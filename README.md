This website was made for the Girls Who Code summer pathways program & Athena Award. I've since updated it to add new features with stylistic changes and other functions (e.g. a tips generator).
<br>
<br>
--> I began this project over the summer and spent ~4 hours designing and working on functionality. It served as the base for my website for a few months, and I was able to build off of my base level knowledge of HTML and CSS. Utilizing JavaScript, I added a few functional features, such as a randomized tips generator.
<br>
<br>
--> I work with a lot of online safety and digital wellbeing-related initiatives, so I figured this would be an interesting topic to explore through my hobby. My main goal in creating this project was to improve, practice, and hopefully spread some awareness on digital literacy and its importance now.
<br>
<br>
--> My main struggles in creating this were mainly just design-related. I spent a lot of time focusing on smaller details, which certainly lengthened my time spent; however, I'm happy I did spend so much time on this, since it's one of the projects I'm most proud of. I think it showcases my skills pretty well.
